# Practic-4
Висновок по роботі
Тема: Динамічна взаємодія з користувачем: маніпуляції з DOM, обробка подій та використання можливостей BOM у JavaScript.

Виконаний варіант: Варіант Б (Калькулятор вартості підписки та інтерактивний блок відгуків).

Підсумок виконання:
Під час виконання практичної роботи було опановано та закріплено на практиці фундаментальні навички роботи з об'єктною моделлю документа (DOM) та браузера (BOM).

Підключення скриптів: Реалізовано асинхронне завантаження JS-файлу за допомогою атрибута defer. Це забезпечило гарантоване виконання скрипта тільки після того, як браузер повністю побудував DOM-дерево, що запобігає помилкам звернення до неіснуючих елементів.

Маніпуляція з DOM: Засвоєно роботу із сучасними селекторами document.querySelector(). Реалізовано динамічне створення нових DOM-вузлів (document.createElement) для списку відгуків та їх безпечне заповнення за допомогою властивості textContent. Маніпуляцію візуальним станом (зміна світлої/темної теми) реалізовано через роботу з CSS-класами за допомогою classList.toggle().

Обробка подій: Навчився призначати обробники подій через метод addEventListener(). Використано події різних категорій: click (миша), input та change (введення/вибір у формах), submit (відправка форми) та keydown (клавіатура). Виклик event.preventDefault() дозволив перехопити відправку форми та забезпечив оновлення інтерфейсу «на льоту» без перезавантаження сторінки.

Використання BOM: Практично застосовано об'єкт window — реалізовано відстеження зміни розмірів вікна браузера (window.innerWidth, window.innerHeight) через подію resize, а також інтерактивне сповіщення за допомогою alert().
